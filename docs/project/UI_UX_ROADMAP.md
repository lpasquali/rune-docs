# RUNE UI/UX 2026 Modernization Roadmap

This document outlines the strategic initiatives to elevate the RUNE user interface to modern enterprise AI platform standards.

## Completed Epics ✅

*   **Epic 1: Stateful Feedback**
    *   Global Job Manager (Slide-over panel).
    *   Sidebar Notification Badges for active/pending jobs.
    *   Modern styling layer (`modern.css`) with depth, transparency, and refined typography.
*   **Epic 2: Credentials Vault**
    *   In-UI Secret Management for API keys (AWS, OpenAI, Vast.ai).
    *   Secure HTMX integration for masked values and real-time updates.
*   **Epic 3: Decision Matrix**
    *   Redesigned "Compare" view.
    *   Automatic highlighting of "Top Performer" and "Fastest Run".
    *   Detailed comparison grid with score, duration, and cost.

## Current & Upcoming Epics 🚧

*   **Epic 4: Guided Workflows (In Progress)**
    *   Multi-step Stepper for the Benchmark Wizard to reduce cognitive load.
    *   Clear separation of Agent selection, Model/Infrastructure configuration, and Review.
*   **Epic 5: Export & Reporting (In Progress)**
    *   JSON export functionality for raw benchmark data.
    *   PDF export / Print-optimized views for stakeholder reporting.

## Future Considerations 🔮

*   **Agent Fine-Tuning**: UI for configuring agent-specific parameters (e.g., search depth, tool permissions).
*   **Live Queue Management**: Enhanced controls for aborting/pausing active benchmark suites.
*   **Resource Telemetry**: Live CPU/RAM graphs for active runs.
