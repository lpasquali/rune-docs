# Cost Efficiency & TCO Reporting

This document defines the standard for reporting the **Total Cost of Ownership (TCO)** for the RUNE platform. It distinguishes between the **Bootstrap (Fixed)** costs required to maintain platform readiness and the **Execution (Variable)** costs generated by specific AI jobs.

## The Cost Tracking Gap

RUNE's built-in `CostEstimator` and `PricingSoothSayer` calculate the **marginal cost** of a job (tokens, specific API fees, live energy). To understand the full ROI, operators must manually combine these with the infrastructure baseline.

---

## Standard TCO Report Template

Use the following structure for monthly stakeholder reviews:

### 1. 🏗️ Infrastructure Bootstrap (Fixed Costs)
*These costs represent the "Table Stakes" required to keep the RUNE platform operational regardless of workload.*

| Component | Resource | Estimated Monthly Cost |
| :--- | :--- | :--- |
| **Compute Node** | e.g. 8 vCPU / 32 GiB | $320.00 |
| **SaaS Database** | e.g. Managed PostgreSQL | $85.00 |
| **SaaS Storage** | S3 Base + Audit Retention | $25.00 |
| **K8s Management** | Cluster Fee (EKS/GKE) | $72.00 |
| **Total Bootstrap** | | **$502.00 / Month** |

### 2. 🤖 Variable Execution Spend (Agent Costs)
*Aggregated data from RUNE `CostEstimator` / `api/v1/metrics/summary`.*

| Cost Category | Quantity / Units | Total Spend |
| :--- | :--- | :--- |
| **LLM Tokens** | Total tokens processed | $X,XXX.XX |
| **Agent API Fees** | Driver Invocations | $XXX.XX |
| **Egress / Data** | Artifact Transfers | $XX.XX |
| **Total Variable** | | **$X,XXX.XX** |

### 3. 📈 Efficiency & ROI Analysis

*   **Total Monthly TCO:** (Fixed + Variable)
*   **Total Jobs Processed:** Count from `jobs.db`
*   **Fully Burdened Cost Per Job:** (TCO / Jobs)
*   **Capacity Utilization Rate:** (Avg Concurrent Jobs / Max Concurrent Jobs)

## Sizing Baseline for Bootstrap Calculation

When calculating your fixed baseline, use the following concurrency targets as a guide for your node sizing:

| Concurrent Jobs | Recommended Node (vCPU/RAM) | Bootstrap Est. |
| :--- | :--- | :--- |
| **1-10** | 2 vCPU / 8 GiB | ~$120/mo |
| **11-25** | 4 vCPU / 16 GiB | ~$240/mo |
| **26-50** | 8 vCPU / 32 GiB | ~$500/mo |

---

## Optimization Strategies

1.  **Spot Instances**: Move RUNE API replicas to Spot nodes. Since the database and storage are SaaS (External), pod interruptions are non-destructive.
2.  **Rightsizing**: If the **Capacity Utilization Rate** is consistently below 30%, downscale the node type in the next maintenance window.
3.  **Audit Retention**: Set an S3 Lifecycle Policy to transition older artifacts to cheaper storage tiers (e.g., Glacier) to keep the Storage Bootstrap flat.
